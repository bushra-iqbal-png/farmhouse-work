# 🏡 AL JANNAT Farmhouse Website

A front-end website project for **AL JANNAT Farmhouse**, designed to present farmhouse facilities, packages, and visitor information through a visual web experience.

## 📌 Project Overview

This project showcases a farmhouse website interface built using HTML, CSS, and JavaScript. It provides a foundation for presenting the farmhouse, its facilities, and information for potential visitors.

## ✨ Website Highlights

- **Home:** Introduces the farmhouse website.
- **About:** Provides space for farmhouse information.
- **Facilities:** Showcases available facilities.
- **Packages:** Presents farmhouse packages.
- **FAQs:** Organizes frequently asked questions.
- **Contact:** Provides contact information.
- **Virtual Tour:** Provides a section for showcasing the farmhouse visually.

*The sections listed above describe the website's intended presentation. Actual functionality depends on the implemented code.*

## 🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and layout
- JavaScript — Client-side interactivity

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder on your computer.
3. Open `index.html` in your web browser.
4. Explore the website and its available sections.

No backend setup is required to view the static HTML pages.
